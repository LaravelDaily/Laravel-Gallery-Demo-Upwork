Summary
I am looking for a skilled PHP developer to build a clean, responsive web-based Art Gallery. The goal is to create a digital space where I can showcase (and eventually manage) a collection of artworks.

Core Tech Stack:

Backend: PHP (Framework preferred: Laravel, CodeIgniter, or Slim).

Database: MySQL.

Frontend: Simple Bootstrap or Tailwind CSS (Clean, gallery-style UI).

Key Features Required (The MVP):

Public Gallery View: A grid-based homepage displaying artwork thumbnails with titles.

Artwork Detail Page: Clicking an image opens a dedicated page with a high-res view, description, medium, and artist name.

Admin Dashboard (Secure): A simple login area where I can:

Upload new images.

Edit/Delete existing entries.

Categorize art (e.g., "Oil Paintings," "Digital," "Sketches").

Responsive Design: Must look great on both desktop and mobile.
